# ضمان الجودة

## 1. الفحص الآلي

```bash
npm run verify
```

يشغّل فحص Manifest وCSP والأذونات والملفات والخطوط، ثم 48 اختبارًا تغطي:

| الملف | ما يحرسه |
|---|---|
| `tests/settings.test.mjs` | عقد الإعدادات، تطبيع النطاقات، أسبقية قواعد المواقع، المظهر. |
| `tests/background.test.mjs` | تخزين Service Worker، الترحيل، الشارة، بوابة الإيقاف العام. |
| `tests/options.test.mjs` | دورة تحرير المواقع، منع «التخصيص الشبح»، قبول كل نطاق يقبله العقد المشترك. |
| `tests/contract.test.mjs` | تطابق نسخة العقد داخل `content.js` مع `src/shared/*`، وعدم وجود رسائل ميّتة. |
| `tests/design-system.test.mjs` | طبقة الرموز الواحدة، أرضية 11px، غياب الألوان الخام، تطابق كتلتي المظهر الداكن. |
| `tests/ui-separation.test.mjs` | فصل مظهر الأداة عن أوضاع الصفحة، وصدق اللوحة، وامتناع المحرك عن تلوين الصفحات. |

## 2. الفحص في المتصفح

بعض السلوك لا يمكن اختباره دون DOM حقيقي، والمشروع بلا تبعيات. لذلك توجد بيئة تشغيل محلية
تُحمّل الكود المشحون نفسه مع محاكاة `chrome.*`:

```bash
npm run harness
```

| العنوان | يغطّي |
|---|---|
| `/tests/harness/popup.html` | اللوحة كاملة. المعاملات: `?theme=dark`, `?page=protected`, `?page=reload`, `?host=…`, `?readingRoot=false` |
| `/tests/harness/options.html` | صفحة إدارة المواقع كاملة. |
| `/tests/fixtures/engine-regressions.html` | تراجعات المحرك في 1.2: تبديل `class`، إعادة كتابة `style`، رشقة التخزين. |
| `/tests/fixtures/real-article.html?mode=reading` | مقال عربي/إنجليزي بخط مصمم واتجاه صريح وكود وأزرار. |
| `/tests/fixtures/github-like-grid.html?mode=reading` | تطبيق شبكي مع شريط جانبي ومقال داخلي. |
| `/tests/fixtures/app-no-article.html?mode=reading` | تطبيق ديناميكي بلا مقال موثوق. |

### تشغيل المحرك على صفحة حقيقية

سياسات CSP تمنع حقن السكربت في المواقع مباشرة، لذا تُلتقط الصفحة ثم تُشغَّل محليًا:

```bash
curl -sL -A "Mozilla/5.0 … Chrome/131" "https://github.com/<user>" -o /tmp/page.html
```

ثم استبدل الروابط النسبية بمطلقة، احذف سكربتات الصفحة و`<meta http-equiv="Content-Security-Policy">`،
وأضف قبل `</body>`:

```html
<script src="/tests/harness/page-mock.js"></script>
<script src="/src/content/content.js"></script>
```

ضع الملف داخل المستودع مؤقتًا وافتحه عبر `npm run harness`. لا تُضِف اللقطات إلى المستودع.

تقبل صفحات `fixtures/` أي مفتاح من عقد الإعدادات كمعامل استعلام، مثل
`?mode=reading&fontSize=18&textWidth=88&reduceVisualNoise=true`.

## 4. قبل أي إصدار

1. `npm run verify`.
2. كرّر صفوف «تطبيق GitHub-like» و«تطبيق بلا مقال» و«تبديل `class`» عبر بيئة المتصفح أعلاه،
   خصوصًا بعد أي تعديل على `src/content/content.js`.
3. حمّل النسخة غير المضغوطة في Brave الحالي وجرّب **GitHub وYouTube وSubstack وويكيبيديا**
   وصفحة عربية وأخرى مختلطة. تحقّق أن الخط تغيّر وأن التخطيط لم يتحرك.
4. اختبر اللوحة على تبويب `brave://` وعلى تبويب عادي كان مفتوحًا قبل تثبيت الإضافة
   (يجب أن يظهر «أعد تحميل الصفحة»، لا «صفحة محمية»).
5. `npm run package`.
